A quiet way out of a panel — "see all", "read the ruling", "2025 draft board →".

```jsx
<MonoLink href="/draft/2025">2025 draft board →</MonoLink>
```

Use instead of a second `Button` next to a real one. Render it only when it leads somewhere: an instructional sentence inside an `<a href="#">` jumps to the top of the page when clicked.
