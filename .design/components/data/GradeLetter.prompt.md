A franchise grade on the A-F ramp — the one letter in the system that carries colour.

```jsx
<GradeLetter grade="A" size={78} />
<GradeLetter grade="C+" size={15} />
```

The ramp uses `--pos-strong`/`--neg-strong`, not the figure pair: at this size on a pale identity tint `--pos` measures 2.90:1 and misses the 3:1 large-text floor. Same ramp everywhere, so the same glyph always means the same thing.
